# Screens

Written by `bun run --cwd apps/web screens` against the mock. Every surface is checked at 1440, 1024 and 390 px in light and dark for horizontal overflow and console errors; the committed images are 1440 light, 390 light and 1440 dark.

- `design-sheet` — The living component sheet at #/design: every primitive in every state.
- `sign-in` — Sign-in: magic link, and the OAuth buttons the adapter reports as available.
- `home` — Home with the day panel: composer first, then active plans and recent chats.
- `chat-working` — The dinner conversation while Nova works: trail with say and action steps, sources with logos, Pause in the composer.
- `chat-decide` — The result card whose primary button decides the calendar permission, the draft with explicit send, the trail collapsed.
- `chat-done` — The finished turn: card confirmed with the receipt and undo, draft still unsent, reactions inline.
- `chat-browser` — The browser task card and the docked browser panel while Nova books the table; hidden entirely when the adapter reports no browser.
- `chat-question` — A question with keyboard answers (1–4) and the unknown-outcome-free plain turn with sources.
- `chat-plain` — A plain answer with its one source; nothing to decide.
- `command-palette` — The command palette (⌘K) with typed results across chats, plans, tasks, events, connections and actions.
- `plans` — Plans with the sheet open on Japan: milestones with assignees, linked chat and file, Ask Melete about this plan.
- `agents` — Agents with Nova open in the editor: look, the nine states, the face wall, templates.
- `automations` — Automations: sentence triggers, run history with retry, test run.
- `settings-memory` — Settings › Memory in plain language with edit, delete and why.
- `settings-connections` — Settings › Connections with the available → connecting → connected → error states and what each may do.
- `settings-rules` — Settings › Rules: standing grants with revoke.
- `onboarding-welcome` — Setup step 1: welcome, name, and the morning brief.
- `onboarding-tour` — Setup step 2: the tour, only the stages the adapter reports as available.
- `onboarding-connect` — Setup step 3: plug in apps.
- `onboarding-agent` — Setup step 4: meet your first agent, with import SVG/PNG.
- `onboarding-know-you` — Setup step 5: four answers that become memory items.
- `phone-drawer` — The phone layout with the sidebar drawer open.
- `phone-day` — The phone layout with the day panel sheet open.
