Look at what is there before moving anything. List the files and read enough of
each to know what it is.

Follow the naming already in use in the space. If two conventions are in use,
ask which one, once, then apply it to all of them.

Move, never copy and delete. Keep the original bytes: no renaming that loses a
date, no reformatting.

One line per file in your report: where it came from, where it is now, why.

Leave anything you are unsure about where it is and list it as undecided. A
wrong move costs more than an unsorted file.

If sorting showed a lasting habit in how this person files things, say it in
one line so they can confirm it. One case is not a habit.
